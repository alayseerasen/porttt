# alice erasen.exe — portfolio

Статичный адаптивный сайт-портфолио в эстетике Webcore / ретро-интернета начала 2000-х.

## Запуск
Открой `index.html` в браузере. Сборка, сервер и база данных не нужны.

## Что заменить перед публикацией
1. В `index.html` найди `href="#"` у элементов с классом `placeholder-link` и вставь настоящие ссылки на свои профили и релизы.
2. Замени `artist@example.com` на публичный контактный email (два места: текст и `mailto:`).
3. Замени демонстрационные названия релизов, годы, описания и CSS-обложки на свои.
4. При желании поменяй текст адресной строки `https://alice-erasen.example/` на адрес своего сайта.

## Файлы
- `index.html` — содержимое сайта.
- `style.css` — весь дизайн и адаптивность.
- `script.js` — активное меню, уведомления о незаполненных ссылках и Pixel Mode.

## Публикация
Можно бесплатно разместить как статический сайт на GitHub Pages, Cloudflare Pages или другом статическом хостинге.
